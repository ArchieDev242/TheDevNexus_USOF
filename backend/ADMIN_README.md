# TheDevNexus USOF - Admin Panel Setup

## 🚀 Запуск проекту

### Основний сервер
```bash
npm start
# або для розробки
npm run dev
```
Буде доступний на: http://localhost:3000

### Адмін-панель
```bash
npm run admin
# або для розробки
npm run admin:dev
```
Буде доступна на: http://localhost:4001/admin

## 🔧 Налаштування AdminJS

### Встановлені пакети:
- `adminjs` - основна бібліотека
- `@adminjs/express` - інтеграція з Express

### Функціональність адмін-панелі:

#### 👤 Користувачі
- ✅ Перегляд всіх профілів
- ✅ Створення користувачів/адмінів
- ✅ Редагування даних профілю
- ✅ Видалення користувачів
- ✅ Фільтрація та пошук

#### 📝 Пости
- ✅ Перегляд всіх постів (включно з неактивними)
- ✅ Зміна категорії поста
- ✅ Встановлення статусу active/inactive
- ❌ Редагування контенту (заборонено навіть для адмінів)
- ✅ Видалення постів

#### 📁 Категорії
- ✅ Створення нових категорій
- ✅ Перегляд всіх категорій
- ✅ Редагування категорій
- ✅ Видалення категорій

#### 💬 Коментарі
- ✅ Перегляд всіх коментарів
- ✅ Зміна статусу active/inactive
- ❌ Редагування контенту (заборонено навіть для адмінів)
- ✅ Видалення коментарів

#### ❤️ Лайки
- ✅ Перегляд всіх лайків на пости та коментарі
- ✅ Створення лайків/дизлайків
- ✅ Видалення лайків

## 🔐 Авторизація

Для входу в адмін-панель потрібен акаунт з роллю `admin` в базі даних.

### Створення першого адміна:
```sql
INSERT INTO users (login, full_name, email, password, role, email_verified) 
VALUES (
    'admin', 
    'Administrator', 
    'admin@thedevnexus.org', 
    '$2b$12$hash_your_password_here', 
    'admin', 
    1
);
```

Або використайте bcrypt для хешування пароля:
```javascript
const bcrypt = require('bcrypt');
const hashedPassword = await bcrypt.hash('your_password', 12);
```

## 🛠️ Налаштування

### Змінні середовища (.env):
```env
ADMIN_PORT=4001
ADMIN_COOKIE_SECRET=your-secure-cookie-secret
ADMIN_SESSION_SECRET=your-secure-session-secret
```

### Безпека:
- ✅ Автентифікація через email/password
- ✅ Сесії з cookie
- ✅ Перевірка ролі адміністратора
- ✅ Захищені маршрути

## 📊 Особливості

1. **Окремий сервер** - адмін-панель працює на окремому порту
2. **Обмежене редагування** - контент постів і коментарів не можна редагувати
3. **Статуси** - можна встановлювати active/inactive для контенту
4. **Фільтрація** - адмін бачить всі пости, включно з неактивними
5. **Безпека** - тільки користувачі з роллю 'admin' мають доступ

- Завжди використовуйте безпечні паролі для адмін-акаунтів
